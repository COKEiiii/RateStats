# 完全本地的纯文字流程

浏览器读取银行官网可见文字和结构化表格；PyMuPDF 读取 PDF 文本。LLM 只接收文字，输出按 schema 校验，再检查来源摘录、行列关系、数字、单位、金额边界、重复、覆盖与有效期。无文字或上下文超限时明确失败，不能静默截掉后续来源。

截图不进入模型。现在按产品表、必要说明区域和 PDF 整页留证，同一表或 PDF 页由文字任务共用一张图片，不生成逐行逐格截图；发现页面只留概览。网页文字、HTML、原始 PDF 和完整性校验继续保存。只有图片的资料需要人工补录或提供可核实文字，不会调用 VLM。原模型响应不被人工修正覆盖；修正保存在单独审计记录。

银行官网和附件采集需要网络。模型推理使用本机回环地址上的 Ollama，数据处理和 Excel 写入在本机完成。安装时会联网下载依赖、浏览器和模型；日常推理采用本地文字模型。邮件是独立的可选交付步骤，启用并确认后，四份工作簿按保存的发送方式提交至配置的 SMTP 服务器。

项目使用独立 Python 虚拟环境、Playwright、openpyxl、PyMuPDF 和桌面 Excel。已完成交付可在本地通过哈希与原生打开记录复核。安装、续跑与可选邮件操作见 [README](../README.md) 和 [一键运行说明](../一键运行说明.md)。
