# 文字提取缓存与扩展

转录缓存按文字任务复用，键包含完整请求、模型摘要、Ollama 版本与适配器指纹。适配器指纹可来自提取代码或提示词、schema 和版本号。批次内响应保存在对应运行目录，共享缓存通常位于 `data/model-response-cache/`。来源、模型或契约改变，缓存损坏或过期时重新提取。缓存命中后仍要核验本期资料日期、原文和覆盖。

较大的表格按行分批，长文本按段处理。转录差异触发限定次数的本地重读，原始页面、截图和 PDF 仍供对照。全量批次的「识别修复汇总」可检查参与重读的任务、处理方法和仍需复核的项目。无可读文本的 PDF 交由人工核实。

扩展银行先适配来源读取、文字表头与单位，再补规则和回归样例；新币种或展示期限同时修改两份 Excel 映射。现有业务和工作簿约束见 [一键运行说明](../一键运行说明.md)，测试时同时核对实际期限和来源完整性。
