# 本地文字模型

只使用 Ollama 的文字接口，默认模型 `qwen3.5:4b`。模型本身可能具备图像能力，本项目不会发送图像，也不检查 vision 能力。另一台电脑可复用该机已有的同名权重。

安装 Ollama 后执行 `ollama pull qwen3.5:4b`。双击项目根目录的 `检查本机运行环境.command` 可检查或启动本机服务。已有服务会被复用。

配置保存在 `config/project.local.json` 的 `models` 中：`text_model` 为模型名，`num_ctx` 为上下文长度，`num_predict` 为回复上限，`max_text_chars` 为文字上限，`timeout_seconds` 为超时。修改后运行模型探测和回归检查。采集、核验和格式交付的阶段日志可从全量批次的「查看运行记录」打开。

本机专用的 Ollama 程序和模型目录可写入 `config/ollama.runtime.local.json` 的 `binary`、`model_directory`；留空使用已安装程序及其默认目录。不要上传这份配置。`RATE_OLLAMA_URL` 可覆盖回环服务地址，`RATE_OLLAMA_BINARY` 可覆盖程序路径。

用 `.venv/bin/python -m scripts.run_all --check` 启动或复用本地服务并检查整套依赖。文字探测使用 `.venv/bin/python -m scripts.probe_local_model --out data/model-probe`，检查输出的 `status.json` 和原始响应。探测用于确认模型可用，具体报价仍需通过批次的来源、单位和覆盖检查。日常续跑见 [统一运行入口](本机统一运行.md)。
