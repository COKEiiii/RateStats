# SGD 促销与人工修正

适配范围由 `config/workbook-policy.json` 和来源配置决定。实际可用报价以本轮采集和核验结果为准，未采集或未核实的来源不补成最新数值。历史测试资料不代表当前官网。

## 人工修正

1. 双击 **人工修正入口.command**，打开本机 SGD 复核页面（端口 8765）。挂牌和外币促销分别使用 **挂牌人工修正入口.command**（8766）和 **外币促销人工修正.command**（8767）。页面跟随对应阶段的最新输出，开始前核对页面显示的批次和资料日期。
2. 按银行、复核状态或关键字筛选。展开报价，可对照文字提取、来源文字、官方链接和原始截图。
3. 可确认、采用文字结果、修改字段、排除报价、撤销修正。必须填写复核人和原因。金额、渠道等身份字段有差异时会显示多条记录；核实后保留正确条目，排除错误条目。
4. 需要补录时使用“补录未抓到的 SGD 促销报价”，填写来源网址和原文摘录。补录明确记为人工提供，不声称通过模型核验；本次补录不自动带到下一期。
5. 保存后点击 **重新生成两份表格**。调研主报价、最高汇总和彩虹排序会一起重新计算，输出到独立目录。失败时查看 `data/manual-rebuild.log`。
6. 核对修正后的调研表和彩虹表，再运行 **确认本期作为历史底稿.command**。终端会显示待登记的 SGD 输出，输入 `YES` 后登记。需要发送修订后的全量交付时，应先生成通过校验的四份工作簿，再按 [邮件说明](../README.md#发送结果邮件) 选择对应批次。

利率和产品显示名的修正默认跨期沿用，按银行、产品、实际期限、客群、渠道、金额等身份匹配。资格、有效期或计息口径改变时不会盲目沿用；新的来源校验失败仍要求重新处理。资格、金额、期限等修正仅作用于当前证据期，保存时取消“跨期沿用”。撤销保留旧审计记录。

审计记录保存在 `data/manual-review.json`，来源则在对应 `runs` 批次的 `run.json` 和证据目录。多窗口同时保存会校验版本，生成期间暂停编辑。入口只监听本机地址。
