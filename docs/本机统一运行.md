# 统一运行入口

先按 [README](../README.md#在另一台电脑安装) 完成首次安装，再用「检查本机运行环境.command」检查 Python、Chromium、Excel 和本地模型。通过后运行「一键运行.command」。程序依次执行 SGD 促销、挂牌、外币促销、Premier 同步、增幅检查和四份文件交付。

项目初始设置使用 `inputs` 内的两份完整历史底稿和 `templates` 内的两份样板。可通过「选择处理文件.command」选择输入。运行证据在 `runs`，工作簿和交付检查在 `outputs`，两者一起保留以便续跑、审计和发送。失败后打开「继续上次全量任务.command」，按日期、启动时间或批次号搜索。当天实时批次和未完成的历史重建批次可按断点继续。

完成后可通过「发送结果邮件.command」搜索并选择批次，预览附件和收件人，再确认发送。发送方式由「邮件设置.command」保存，可选择一封或两封。具体步骤见 [一键运行说明](../一键运行说明.md)。旧视觉路线的通过记录属于历史证据，当前流程以本批文字核验为准。
